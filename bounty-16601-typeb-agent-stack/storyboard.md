Show a clean title card: **Can a blockchain verify a machine?** Cut to a real/vintage-computer silhouette or a screen capture of the canonical RustChain README heading. Highlight the words “DePIN for Vintage Hardware” and “Proof of Antiquity.”

Use a two-column generated card: “service provided” on the left and “machine identity / physical substrate” on the right. Then show the README wording around hardware-attested agent identity and Sybil resistance.

Show the documented multiplier table. Zoom only on the PowerPC G4 2.5x example and modern x86-64 1.0 baseline. Overlay: **Protocol weighting — not a speed benchmark or guaranteed earnings.**

Show a four-node diagram: RustChain identity → Beacon discovery → BoTTube media → cryptographic payments. Use only project names and canonical links from the README. Avoid implying all components share identical security guarantees.

Animate many identical VM icons collapsing into a smaller set of physical-machine icons. Overlay: **Goal: make cheap identity replication harder.** Then return to the multi-signal fingerprint list.

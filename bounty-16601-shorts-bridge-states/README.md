# Bounty #16601 — Package C: Bridge States

**Package:** C — Shorts / clip kit (15 RTC)

**Pitch:** A sub-60-second vertical explainer showing that RustChain's documented cross-chain bridge is a state machine: a RustChain-origin deposit is operator-assisted/admin-authenticated, and a transfer can move through `pending`, `locked`, and `confirming` before `completed`.

This package is deliberately distinct from earlier kits about antiquity multipliers, wallet-history settlement, hardware attestation, signed wallet transfers, and epoch structure.

Files: `script.md`, `capture-instructions.md`, `metadata.md`, `SOURCES.md`.

No third-party media is required. All visuals can be captured from the public RustChain API reference or generated as plain text cards. AI assistance was used; technical claims were checked against the current public API reference before submission.
